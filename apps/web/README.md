# Apps — Web (Next.js Frontend)

The PaperToProd web client — built with Next.js, TypeScript, and Framer Motion.

## Setup

```bash
cd apps/web
npm install
npm run dev
```

The frontend will be initialized with Next.js during Phase 0.4.
See Doc 06 (UI Design Specification) and Doc 07 (Design System) for full design specs.

## Key Pages
- Landing / Marketing
- Sign Up / Log In
- Job Submission
- Job Progress (real-time pipeline visualization)
- Job Results (Fidelity Score, download, GitHub push)
- Job Failure / Partial Result
- Dashboard / Job History
- Repository Explorer
- Fidelity Report
- Workspace Settings
- Personal Settings
- Public Gallery
- Shared Read-Only Job View
